# 측정 — ROE 최상위 칸을 닫아야 하나

> 2026-08-10 실행. 사전등록: [`2026-08-10-roe버킷-사전등록.md`](2026-08-10-roe버킷-사전등록.md)
> **사전등록 문서는 이 측정 뒤에 고치지 않았다.**
> 발단: [ADR-0038](../adr/0038-street-targets-are-not-an-answer-key.md) ㉮

## 한 줄

**관문 둘 다 통과했다 — 다만 "좋아져서"가 아니라 "나빠지지 않아서"다.**

| | 결과 |
|---|---|
| 1차 관문 (LOO 오차) | 후보 넷 다 통과. **좋아진 곳은 미국 PBR 하나뿐**(−3.9%) |
| 2차 관문 (한국 백테스트) | 검증 IC **0.098 → 0.098**. 나빠지지 않았다 |
| 한국 화면 | 판정 **1.8%** 변화 · 적정가 중앙 −0.0% |
| 미국 화면 | **아직 안 쟀다** — §10 |

**개선의 근거는 미국에 있고, 미국은 백테스트로 검증되지 않는 시장이다**
([ADR-0030](../adr/0030-us-does-not-replicate.md) H1 t=0.92). 이 비대칭이 이 측정의
핵심이고, 채택 판단이 걸리는 지점이다.

## 재현

```bash
python scripts/check_roe_buckets.py KR
python scripts/check_roe_buckets.py US
```

두 번 돌려 같은 값이 나오는 것을 확인했다(스냅숏이 캐시돼 있다). ADR-0037의 교훈대로
**한 스냅숏 위에서 네 안을 모두 적합한다** — `check_warranted.py`를 두 번 돌려 비교하면
그 사이 표본이 달라진다.

| **KR** per | 0.581 | +0.0% | +0.0% | +0.1% |
| **KR** psr | 0.897 | +0.0% | +0.1% | +0.1% |
| **KR** ev_ebitda | 0.670 | +0.1% | +0.2% | −0.0% |
| **US** pbr | 0.443 | **−3.9%** | **−4.4%** | **−4.5%** |

## 2. 왜 미국만 좋아지나 — 칸에 표본이 얼마나 몰려 있나

| | KR `>15%` 칸 | US `>15%` 칸 |
|---|---|---|
| pbr | 244 / 2,531 (**9.6%**) | 516 / 1,336 (**38.6%**) |
| per | 237 / 1,527 (15.5%) | 578 / 1,213 (**47.7%**) |
| psr | 193 / 1,990 (9.7%) | 581 / 1,410 (41.2%) |
| ev_ebitda | 167 / 1,373 (12.2%) | 535 / 1,223 (43.7%) |

**미국은 전 종목의 40% 안팎이 ROE 더미 하나에 묶여 있다.** 한국은 10% 남짓이다.
쪼개서 얻을 것이 미국에 훨씬 많은 것이 당연하다 — 한국은 그 칸이 얇아 나눌 것이 별로 없다.

## 3. PBR만 좋아지고 PER은 안 좋아진 것은 우연이 아니다

잔여이익 모형이 그대로 예측한다:

```
P/B = (ROE − g) / (r − g)            ROE에 **선형** — 계속 올라간다
P/E = (ROE − g) / (ROE · (r − g))    ROE가 커지면 1/(r−g)로 **수렴한다**
```

**ROE가 아주 높은 구간에서 PER은 더 오르지 않는다.** 그러니 그 구간을 한 칸으로 묶어도
PER은 손해가 없고, PBR은 손해가 크다. **측정이 이론과 정확히 맞았다.**

## 5. ⚠ 평균 오차가 그대로여도 **개별 배수는 크게 움직인다**

*"KR은 오차가 안 변했으니 KR 판정도 안 변한다"*는 **틀린 추론이다.** 확인했다
(업종·시총을 시장 중앙값으로 고정하고 ROE 칸 효과만 본 값):

| 종목 | ROE | PER A→B | PBR A→B |
|---|---|---|---|
| **SK하이닉스** | 45.7% | **−9.8%** | +14.2% |
| 삼성전자 | 17.6% | +4.6% | −6.3% |
| Apple·MSFT·KO·GOOGL | >25% | −2.5% | **+36.8%** |
| J&J·Walmart | 15~25% | +1.7% | **−18.5%** |

**①과 ⑤가 같은 회귀를 쓰므로 판정의 77%가 이 한 줄에 걸려 있다**(가중 ① 38.5 + ⑤ 38.5).

## 6. 그래서 남는 곤란한 점

```
개선이 있는 곳  →  미국
검증이 되는 곳  →  한국 (ADR-0030: 미국은 재현되지 않는다, H1 t=0.92)

한국은 오차가 안 좋아지는데 개별 배수는 크게 움직인다 — 근거 없이 판정을 흔드는 셈이다
```

**2차 관문(한국 백테스트)이 이것을 판정한다.** IC가 나빠지면 *"근거 없는 뒤섞기가 실제로
해로웠다"*는 뜻이므로 기각한다.

## 7. 사전등록한 예측 채점 — 틀린 것을 적는다

| | 예측 | 결과 |
|---|---|---|
| 1 | 삼성전자는 B로 갈린다 | **맞음** |
| 2 | SK하이닉스는 D로도 어려울 것 (그 구간에 데이터가 없어서) | **틀림** — D에서 갈렸고 포화도 0이었다 |
| 3 | LOO는 거의 안 움직이거나 조금 나빠질 것 | **반만 맞음** |

**예측 3을 반만 맞힌 이유가 배울 점이다.** 나는 `P/E`가 ROE에 대해 포화한다는 것을 근거로
*"안 좋아질 것"*이라고 적었다. **PER에서는 맞았다.** 그런데 **같은 논리를 `P/B`에 적용하지
않았다** — P/B는 ROE에 선형이라 포화하지 않으므로 예측이 달랐어야 했다.
**내 근거가 다리마다 다른 답을 내는데 하나로 뭉뚱그렸다.**

## 8. 한계 — 사전등록에 적은 그대로

- **KR·US 각 한 시점의 횡단면이다.** 시점을 바꾸면 달라질 수 있다
- **LOO는 계수만 leave-one-out이고 특징 설계는 전체 표본으로 정한다.** ROE 구간을 후보마다
  바꾸는 이번 측정에서는 특히 중요하다 — 구간 자체가 leave-one-out되지 않으므로 **낙관 쪽으로
  치우친 값**이다
- **LOO 오차가 좋아지는 것이 판정이 좋아지는 것은 아니다.** 시장 배수를 더 잘 맞히는 모델은
  진짜 미스프라이싱까지 '적정'으로 흡수할 수 있다(사전등록의 경고 절)

## 9. 2차 관문 — 한국 백테스트: **나빠지지도 좋아지지도 않는다**

같은 `raw/`(지문 `sha256:4e4974876255b6fa` · 3,876파일)로 같은 코드에서 ROE 구간만
갈아 끼워 빌드했다. **지문이 기준선 매니페스트와 정확히 일치한다**(ADR-0037 요구).
판정 코드는 기준선 빌드 커밋(`838b4e5`) 이후 `src/` 변경이 하나도 없다.

| | 선택 IC | 검증 IC | 검증 t | 검증 Q5−Q1 | 단조 | 양(+) | 커버 |
|---|---|---|---|---|---|---|---|
| **B1 현행(기준선)** | 0.062 | **0.098** | 4.56 | 2.8% | 0.08 | 5/5 | 99% |
| **C4 ROE칸 25% 쪼갬** | 0.063 | **0.098** | 4.72 | 2.8% | 0.09 | 5/5 | 99% |

**검증 IC가 소수점 세 자리까지 같다.** 사전등록한 기각 조건(*"IC가 나빠지면 기각"*)에
걸리지 않는다.

### 화면이 얼마나 바뀌나 (한국)

```
판정이 바뀐 행   134 / 7,656  (1.8%)
적정가 변화      중앙 -0.0% · 90분위 +1.3% · 최대 +48.5%
```

| 판정 | A → B |
|---|---|
| 크게 저평가 | 2,686 → 2,673 (−13) |
| 저평가 | 547 → 560 (+13) |
| 적정 수준 | 741 → 737 (−4) |
| 고평가 | 852 → 856 (+4) |
| 크게 고평가 | 2,830 → 2,830 (0) |

**한국에서는 사실상 안 움직인다.** §1의 LOO가 안 변한 것과 앞뒤가 맞는다.

**⚠ 그런데 §5에서 SK하이닉스 PER이 −9.8% 움직였다.** 개별 종목은 움직이는데 분포는
안 움직인다 — 서로 상쇄되기 때문이다. **"판정이 1.8%만 바뀐다"를 "아무도 영향받지
않는다"로 읽으면 안 된다.**

## 10. 2차 관문 — 미국 (진행 중)

**정작 개선이 있는 시장은 미국인데 아직 안 쟀다.** 미국 PBR 배수가 ±37% 움직이므로
화면 파급이 한국보다 훨씬 클 수 있다. ADR-0035가 ②를 뺄 때 *"판정 26% 변화"*를 먼저
재고 결정한 것과 같은 이유로, **채택 전에 파급 범위를 알아야 한다.**

**미국은 기준선도 새로 만들어야 한다** — 저장소의 `data/backtest_us/panel.parquet`은
2026-08-06 것이라 **② 제거(ADR-0035) 이전이고 매니페스트도 없다.** 스테일이다.

⚠ **미국 백테스트의 IC는 채택 근거로 쓸 수 없다**([ADR-0030](../adr/0030-us-does-not-replicate.md):
미국에서는 재현되지 않는다, H1 t=0.92). 여기서 얻으려는 것은 **예측력이 아니라 파급 범위**다.

## 11. 실행 기록 — 다음 사람이 같은 데 걸리지 말라고

**패널 빌드가 yfinance 레이트리밋으로 한 번 실패했다.** 우리 코드가 아니라 지수(`^KS11`)
이력 요청 **한 건**에서 걸렸다(인증서는 정상 — `curl 404`이지 `77`이 아니다, ADR-0027).
종목 데이터는 `raw/`에서 읽으므로 **패널 빌드의 네트워크 호출은 이 한 건뿐**이다.
4분 간격 재시도 루프로 **2회째에 성공**했다.

**기록해 둘 실수 하나** — 첫 실행을 이렇게 짰다:

```bash
python scripts/backtest_panel.py ... > log 2>&1; echo "EXIT=$?"; tail -5 log
```

`$?`가 파이썬이 아니라 **`echo` 직전 명령의 코드**를 읽는 것까지는 맞았지만, 백그라운드
작업의 최종 종료 코드는 **마지막 `tail`의 것**이 되어 **실패가 성공으로 보고됐다.**
로그에 트레이스백이 있는데 알림은 `exit code 0`이었다.

**재시도 루프는 종료 코드와 산출 파일 존재를 둘 다 본다:**

```bash
if [ "$rc" -eq 0 ] && [ -f data/backtest/panel_roe25.parquet ]; then ...
```
