# ADR-0010: 시장이 장부가를 오래 거부했으면 RIM을 쓰지 않는다 (ADR-0007의 대칭)

- 상태: 채택됨
- 날짜: 2026-08-03
- 관련: [ADR-0007](0007-book-quality-gate-for-rim.md)(장부가 과소 쪽 게이트),
  [ADR-0006](0006-fundamental-verdict-consensus-alongside.md)(판정 = ①②③),
  [ADR-0003](0003-fair-value-weighted-average.md)(RIM 가중 0.231)
- 관련 코드: `src/analysis/valuation.py`의 `_book_quality()`·`_underearning()`·
  `BOOK_REJECTED_PBR`·`UNDEREARN_YEARS`, 진단은 `scripts/check_size_bias.py`

## 맥락

소형주에 저평가 판정이 과하게 뜬다는 관찰에서 시작해, 판정 경로를 복제해 KRX 상장
공통주 2,688종목을 전수 측정했다(`scripts/check_size_bias.py`).

| 시총 구간 | 시총 중앙 | PBR 중앙 | ① 괴리율 | ③ 괴리율 |
|---|---:|---:|---:|---:|
| Q1 최소형 | 211억 | 0.50 | +25.2% | **+103.1%** |
| Q3 중형 | 870억 | 0.71 | +4.2% | +59.1% |
| Q5 최대형 | 11,422억 | 1.44 | −27.5% | −22.7% |

**③의 괴리율과 `1/PBR`의 순위상관이 +0.973이었다.** 우연이 아니라 정의다. RIM은

```
V = B + B·(ROE − r)·w / (1 + r − w)
```

이므로 `ROE ≈ r`이면 `V ≈ B`로 수렴하고, 그러면 괴리율이 `B/P − 1 = 1/PBR − 1`이 된다.
PBR 0.5인 회사는 **계산하기 전에 이미 '+100% 저평가'**다.

실측에서 최소형주는 ROE 6.0% < r 7.2%로 자본비용에 미달하는데도 ③이 +103%를 냈다.
초과손실이 `w = 0.8`로 몇 년 만에 소멸하고 `B`만 남기 때문이다. 즉 **ROE < r을 이미
반영한 뒤에도** 결과는 여전히 "장부가만큼은 된다"였다.

국내 시장에서 PBR은 시총을 따라 0.50 ↔ 1.44로 2.9배 갈린다. 그래서 이 되읽기가 그대로
규모 편향이 된다. 판정 가중을 적용하면 ③의 기여가 +23.8%p로 ①(+9.5%p)의 2.5배였다.

### ADR-0007이 한쪽만 막고 있었다

ADR-0007은 PBR이 **높은** 쪽에서 원인을 갈랐다.

- ㉠ 장부가가 실제보다 작다(무형자산·자사주) → RIM 성립 안 함 → 제외
- ㉡ 장부가는 멀쩡한데 이익이 크다 → RIM은 **필요한 반대 목소리** → 유지

그 대칭이 비어 있었다. PBR이 **낮은** 쪽에도 같은 분기가 있다.

- ㉢ **시장이 일시적으로 싸게 매겼다** → RIM이 반대 목소리를 낼 자리. 이게 이 모형의 존재 이유다
- ㉣ **시장이 오래 장부가를 거부했다** → 그 장부가는 되찾을 수 있는 값이 아니다

`_book_quality()`는 `if pbr <= PBR_GATE ... return done(False, "", "")`로 낮은 PBR을
**아예 따지지 않고** 통과시켰다. ㉢과 ㉣이 갈리지 않은 채 전부 ㉢으로 처리됐다.

## 결정

**5년 PBR 중앙값이 `BOOK_REJECTED_PBR`(0.7) 미만이고, 동시에 최근 3개년 중
`UNDEREARN_YEARS`(2)년 이상 ROE가 자본비용 `r`에 못 미쳤으면 ③을 제외하고
가중치를 ①②로 재배분한다.**

**둘 다** 만족할 때만 제외한다. 하나로는 부족하다.

- 지속적 할인만 있고 자본비용을 벌고 있으면 → ㉢이다. RIM이 말할 자리이므로 **유지한다**.
- 자본비용 미달만 있고 시장이 장부가 위로 매기고 있으면 → 시장이 아직 장부가를
  인정한다는 뜻이다. **유지한다**.
- 5년 PBR을 잴 수 없으면(상장기간이 짧아 밴드 표본 200 미달) **게이트를 열지 않는다.**
  '시장이 거부했다'는 근거 없이 방법을 빼면 신규 상장주에서 ③이 통째로 사라진다.
  못 재는 것과 '미달 0년'은 다르게 다룬다.

임계 0.7과 2년은 ADR-0007의 `INTANGIBLE_SHARE_LIMIT`·`BUYBACK_RATIO_LIMIT`과 같은
성격이다 — 국내 시장 분포를 보고 정한 **판단값이지 데이터로 추정한 값이 아니다**.
(전 종목 PBR 중앙값이 0.71이고 5년 중앙값은 그보다 높게 깔린다. 0.7은 "시장 절반보다
낮은 값이 5년 내내 유지됐다"에 해당한다.)

5년 PBR 중앙값은 ②가 이미 만든 `res.pbr_q[50]`을 그대로 쓴다 — 새로 받아올 데이터가 없다.

## 결과

- 판정이 규모와 붙어 있던 정도가 줄어든다. ③ 기여 +23.8%p가 걸린 종목에서 사라지고
  가중이 ①②로 넘어간다. 다만 ①②도 규모 편향이 있어(①은 rho −0.261) **이 ADR 하나로
  편향이 사라지지는 않는다.** 후속은 ①의 피어 규모창(ADR-0011 예정)과 ②의 국면 의존
  (ADR-0012 예정)이다.
- 제외 사유는 잰 값을 그대로 말한다 — "5년 PBR 중앙값 0.52배 · 3년 중 3년 자본비용 미달".
  ADR-0007과 같이 **원인을 단정하지 않는다**.
- 이 판단이 틀리는 방향을 화면에 밝힌다: 자산 매각·구조조정처럼 장부가가 실현될 계기가
  있으면 우리가 보수적인 쪽으로 틀린 것이다.

## 하지 않은 것

- **파마-프렌치 계열(규모 프리미엄을 `k_e`에 더하기).** 검토했고 계산까지 해봤다.
  최소형주에 +3.0%p를 얹어도 ③ 기여 +23.8%p 중 **3.5%p(15%)만** 걷힌다. `V ≈ B`라는
  구조가 남기 때문에 할인율을 아무리 정교하게 깎아도 닿지 않는다. 반사실 실험은
  `scripts/check_size_bias.py`의 D 섹션에 남겨 두었다.
  덧붙여 한국은 French 라이브러리의 선진국 지역 포트폴리오에 없어(MSCI 기준 신흥국)
  SMB·HML 시계열을 직접 구성해야 하는데, 이는 "무료 데이터·키 없이 동작" 규약과 충돌한다.
- **지속계수 `w`를 ROE−r 부호에 연동하기.** 임계값 없이 연속적이라는 장점이 있지만,
  계산해 보면 PBR 0.5인 종목이 여전히 +67% 수준이라 크기가 부족했다.
- **③ 가중을 종목마다 다르게 하기.** 판정에서 빼지 않으면서 영향만 줄일 수 있지만,
  "왜 이 종목은 ③이 덜 반영됐나"를 화면에 설명해야 해서 이미 복잡한 가중 설명이 더 는다.
- **낮은 PBR이 정말 저평가인지 판정하기.** 이 ADR은 "장부가를 닻으로 쓸 수 있는가"만
  다룬다. 코리아 디스카운트가 시장의 오류인지 구조적 할인인지는 데이터가 아니라
  관점의 문제이고, 이 도구가 답할 것이 아니다.
